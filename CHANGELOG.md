# Changelog

## Unreleased

- Initial iteration: portable, skill-only three-role agent process with entry, orchestrate, and work-unit skills, host integration guides, and validation gate.
- Delegation economics: specifiability test for Lead delegation, corpus-ownership and forfeit rule, late-size-discovery reactive trigger, checkpoint/continue lifecycle status, and an Orchestrator raw-extraction prohibition.
- Delegation economics follow-up: extend the Orchestrator's Context Discipline and raw-extraction prohibition to the Lead, add a Late Size Discovery rule for self-discovered size, extend the specifiability test to read-only and investigation units, require corpus-ownership briefs to carry forward established in-session facts, require read-only Worker reports to itemize every requested fact, and record that a Lead's byte typically costs more than a Worker's under mixed model tiers.
- Delegation economics role-model clarification: name a Lead pre-start split for oversized units, host reconciliation as the Lead's only other direct-extraction right, the delegable categories, per-role read boundaries (Lead reads only its unit's spec and plan plus required diff/evidence; Orchestrator reads only top-level READMEs, backlog, decisions, and vision/architecture docs), a Worker's Lead-only interaction boundary, an escalation ladder by decision blast radius with project dependencies always escalating, the cost-tier rationale, and an Orchestrator technical-consultation path.
- Process overhead reduction: restrict Orchestrator approval to `spec.md` and the plan's semantic sections, making progress, evidence map, attempt counters, residual risks, and final outcome Lead-owned record-keeping; single-source the return thresholds and lifecycle prose in the role skills and `references/scheduling.md`, with README, architecture, the `agent-process.md` template, and the integration guides describing and linking, guarded by a validator check against restatement; retire per-change contract phrase functions by rule once behavior is recorded in `tests/behavioral.md`, removing the lead-lifecycle, delegation-economics, delegation-economics-followup, and context-and-safety-hardening checks; demote `150000` from process prose to a host configuration value; replace the per-dispatch `docs/principles.md` read with brief-named clauses; add a distinct `handover` status so `blocked` no longer carries a terminal meaning, deleting the restated caveats; record attempt counters only once a count exceeds 1; and compress the delegation-decision, corpus-ownership, and late-size-discovery rules without changing their behavior.
- Circuit breakers and revised return thresholds: count attempts, correction rounds, and independent reviews against the stable semantic unit rather than the agent, so the count survives Worker replacement, Lead succession, handovers, and relabeled briefs; trip a breaker on a third attempt, a second correction round, a second independent review, failures that change location but not class, or growing verification volume with no acceptance criterion met, stopping implementation and escalating one tier with a loop report; define a reset as a change of kind and exclude another patch, Worker, review pass, or relabeled brief; add a Worker loop self-check reported on `decision-needed` with `Loop-suspected`; limit a unit to one independent review with its finding set frozen at review time and a confirmation pass that cannot open new in-unit rounds; require new tests to trace to an acceptance criterion; require every unit in a commit to be accepted with no open blocker or unresolved serious finding, limiting fix-forward to defects found after acceptance; type verification commands static or live by what they do rather than by their name; require `state.md` at a second Lead succession or any Expanded trigger; and revise the return thresholds so a Worker targets about 12-16 of its own tool calls and returns by about 20, a Lead returns after 3 completed work units or about 20 of its own tool calls, and the Orchestrator has no fixed dispatch cap but hands over deliberately, with a threshold stated as a scheduling boundary rather than an evidence-validity boundary.
- Context and safety hardening: replace the `wc -c` byte-counting context-ceiling rule with countable-proxy return thresholds (own tool calls, dispatches, completed work units) and a stated preference for exact host telemetry, marked provisional and due for revalidation, framing a threshold return as the normal end of a bounded stint rather than an emergency; require every role to assert its actual role, configured role, and parent as the first line of its first output and dispatch only the tier directly below it; add a destructive-action authorization requirement to brief contents and an irreversible-destruction-outside-version-control escalation trigger; and correct the delegation-economics watchlist's same-material duplication target and Orchestrator cost-share metric.
